# 응원 한 송이

2026 동덕여자고등학교 과학심화진탐아 학술제에서 발표한 1학년 학생들에게
학부모님들이 보내 주신 응원 메시지를 담은 웹페이지입니다.

목화나무에 맺힌 초록 목화를 누르면 하얀 목화솜이 피어나며 메시지가 열립니다.

## 파일 구성
- `index.html` – 페이지 구조
- `style.css` – 디자인 (겨울 밤 테마, 모바일 우선)
- `app.js` – 목화나무 그리기와 목화 여는 동작
- `messages.js` – 응원 메시지 (만족도 조사 I열, 1학년 응답)
- `logo.png` – 학교 로고

## 메시지 수정
`messages.js`의 목록에 문장을 추가하거나 고치면 목화 개수도 함께 바뀝니다.

## 응원 카드 이미지 (`cards/`)
'이 응원을 카드로 저장하기'는 미리 만들어 둔 `cards/01.jpg`~`11.jpg`를 사용합니다.
카카오톡 등 앱 안의 브라우저는 즉석에서 만든 이미지를 저장하지 못하기 때문입니다.
메시지를 고치면 카드 이미지도 다시 만들어야 합니다.
파일이 없으면 화면에서 즉석으로 그려 보여 줍니다.
